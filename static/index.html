⏱️ 自动检测与推送

快捷方案点击即保存：安静模式只即时通知严重 / KEV，普通高危留到每日汇总；合并模式把普通高危先汇集 5 分钟；仅日报会关闭即时告警。

关闭后停止后续自动采集，当前这一轮仍会完成，手动检测仍可用。
关闭后即时告警和每日汇总暂停，待推送内容保留，手动发送仍可用。
仅在高危也即时推送时生效。到期统一发送窗口内的高危；严重 / KEV 不等待。0 表示不合并。
发布日期早于首次入库超过此天数，仅入库不自动推送。0 表示不限；KEV 不受限制，无发布日期按首次入库判断。

相同 CVE 跨源、跨轮和重启后均去重；无 CVE 按来源及公告标识去重，不凭相似标题合并。手动指定记录允许重发。延迟或失败内容不会因等待太久被历史过滤丢弃。

普通高危默认在每日汇总发送；严重 / KEV 采集后即时发送。消息超出通道长度会分条，失败每分钟检查重试。

🎯 推送过滤

影响每日汇总和手动待推送；即时告警等级在上方单独设置。KEV 绕过等级阈值，但仍受产品关键词与标签筛选。
只关心命中这些关键词的产品,适合"只看我司用到的产品"
命中这些关键词的漏洞不推送

🌙 静默时段

普通告警在静默时段保留待推送；符合即时阈值的内容在静默结束后按分钟重试，其他内容等每日汇总。手动推送不受静默限制。

🤖 DeepSeek 公告解读

作用：把公开公告整理为中文「风险、受影响范围、建议操作」。不扫描你的设备、不判断公司是否中招，也不负责决定告警等级。

流程：先发原始告警 → 后台每分钟处理已推送且没有摘要的记录 → 缓存到漏洞列表；后续手动推送可附带已有摘要。首次历史基线不批量调用 AI，不为摘要再补发一轮通知。

仅发送该条公告资料到 DeepSeek；未配置 Key、关闭开关或调用失败，采集和通知仍照常运行。调用按你的 DeepSeek 账号计费；次数上限不是金额上限。失败至少间隔一小时再试，已有摘要复用。

⏰ 每日汇总

只处理符合「每日/手动推送阈值」的剩余待推送记录；没有内容时不发空日报。开启即时告警后，09:00 不是紧急漏洞的等待时间。

所有配置保存后立即生效。业务时区显示在概览页，默认 Asia/Shanghai。
